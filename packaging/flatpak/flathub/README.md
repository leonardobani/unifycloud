# Flathub Submission Files (`dev.leonardobani.unifycloud`)

This directory contains the self-contained, offline-buildable Flathub submission files for **UnifyCloud**, built from source using `flatpak-flutter` and `flatpak-go-mod`.

## Files

- `dev.leonardobani.unifycloud.yml` — Offline Flatpak manifest generated by `flatpak-flutter` (uses `org.freedesktop.Platform//26.08`, `llvm22`, and `golang`).
- `flatpak-flutter.yml` — Template manifest used to regenerate `dev.leonardobani.unifycloud.yml` when updating versions or dependencies.
- `generated/` — Generated Flutter SDK (`3.47.9`) module, `pubspec.json` offline dependency sources, and SDK patch.
- `go.mod.yml` & `modules.txt` — Offline Go module vendor sources for `go_backend/go.mod` generated by `flatpak-go-mod`.
- `dev.leonardobani.unifycloud.desktop`, `dev.leonardobani.unifycloud.metainfo.xml`, `dev.leonardobani.unifycloud.png` — Desktop entry, AppStream MetaInfo, and 512×512 icon.

## Regenerating Sources on Version Updates

1. Update `tag` and `commit` in `flatpak-flutter.yml` (and the Flutter tag if changed).
2. Regenerate Go vendor sources from `go_backend/`:
   ```bash
   cd go_backend
   go run github.com/dennwc/flatpak-go-mod@latest -dest-pref go_backend/ -out ../packaging/flatpak/flathub .
   rm -rf vendor
   ```
3. Regenerate Flutter offline sources:
   ```bash
   cd packaging/flatpak/flathub
   flatpak-flutter.py flatpak-flutter.yml
   ```
4. Validate and build locally in the offline sandbox:
   ```bash
   flatpak run --command=flatpak-builder-lint org.flatpak.Builder manifest dev.leonardobani.unifycloud.yml
   flatpak run org.flatpak.Builder --disable-rofiles-fuse --repo=repo --force-clean --sandbox --user --install --install-deps-from=flathub build-dir dev.leonardobani.unifycloud.yml
   ```

## Submitting to Flathub

1. Fork `https://github.com/flathub/flathub` (using the `new-pr` branch).
2. Create a branch from `new-pr`:
   ```bash
   git checkout -b dev.leonardobani.unifycloud origin/new-pr
   ```
3. Copy the contents of `packaging/flatpak/flathub/` (except this `README.md`) into the root of that branch, commit, push, and open a Pull Request against `flathub/flathub` (`base: new-pr`).
4. Complete domain verification for `leonardobani.dev` as prompted by the Flathub review bot.
